# exercise-5

## Overview

The point of this assignment is to get a little more comfortable with basic memory manipulation. You will be loading some values from variables, and storing them back in a segment of memory - essentially creating an array-like structure. 

Complete the provided `main.s` file using the Venus simulator extension in VS Code.

## Required Work

Required tasks can also be found in the TODO comments in the main.s file, but here is a general overview of what is required:

1. Load `alpha`, add `3`, and store the result at `out + 0`.
2. Load `beta`, add `9`, and store the result at `out + 4`.
3. Load the second word of `pair`, subtract `45`, and store the result at `out + 8`.
4. Reload those three values from `out` into `t0`, `t1`, and `t2`.
5. Print the completion message.

## Grading

- `t0` contains the specified calculated value: 13 points
- `t1` contains the specified calculated value: 13 points
- `t2` contains the specified calculated value: 13 points
- Output contains `Program completed`: 6 points
